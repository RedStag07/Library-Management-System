# Library Management System

This is a simple **Library Management System** made using Python.
The project is designed to manage books and students in a library and also keep track of borrowed and returned books.

## Features

### 1. Book Management

* Add a new book
* Remove a book
* Search for a book
* Check book status

### 2. Student Management

* Add a student
* Remove a student
* Search for a student
* Display all students

### 3. Borrow and Return

* Issue a book to a student
* Return a book
* Check whether a book is available or already issued

## Technologies Used

* Python
* Lists
* Functions
* Loops
* Conditional Statements
* User Input

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Run the Python file:

```bash
python library_management.py
```

5. Select an option from the menu and follow the instructions.

## How It Works

Books and student information are stored using Python lists.

Each book contains:

* Book ID
* Book Name
* Author
* Availability Status

Each student contains:

* Student ID
* Student Name
* Course

The availability of a book changes when it is issued or returned.
